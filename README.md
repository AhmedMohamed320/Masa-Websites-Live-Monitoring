# Masa Pulse Monitor | لوحة مراقبة واستعراض المواقع الحية 🚀

لوحة تحكم واستعراض تفاعلية فائقة السرعة تتيح مراقبة ومتابعة المواقع الرسمية التابعة لمجموعة ماسة في وقت واحد من خلال شاشات مصغرة حية (`iFrames`)، مع نظام فحص تلقائي لحظي لحالة الاتصال (Uptime & Ping Checker) واحتساب زمن الاستجابة بدقة.

---

## 🌟 المواقع المعتمدة في اللوحة (Monitored Websites)

تم ضبط اللوحة افتراضياً على المواقع الأربعة الرسمية:

1. **بوابة العيون (Eyetoora)**: `https://eyetoora.com/ar`
2. **داواتورا (Dawatoora)**: `https://testwebsite.dawatoora.com/`
3. **جنيد ماسة A4 (Juned Masa)**: `https://a4.junedmasa.com/ar`
4. **إطارات جنيد ماسة (Juned Tyres)**: `https://tyres.junedmasa.com/en`

## 🌟 أبرز المميزات (Key Features)

1. **عرض حي ومتزامن عبر الـ iFrames**:
   - تقسيم شبكي مثالي وثابت بنظام **2 × 2** مخصص لعرض المواقع الـ 4 بأعلى وضوح وتناسق مرئي.
   - تحميل ذكي وسلس مع مؤشر تحميل دائري لكل إطار.
   - وضع ملء الشاشة لكل موقع (Fullscreen Expand) لتصفحه بحجم كامل دون مغادرة اللوحة.

2. **نظام فحص الحالة والجاهزية (Uptime & Latency Engine)**:
   - فحص استجابة الخوادم لحظياً واحتساب زمن الاستجابة بالمللي ثانية (`Latency ms`).
   - شارة حالة ذكية لكل موقع:
     - 🟢 **شغال (Online)** مع سرعة الاستجابة.
     - 🔴 **واقع / معطل (Offline)** مع إشعار تنبيهي وزر فتح مباشر.
     - 🟡 **جاري الفحص (Checking)**.
   - شريط إحصائي علوي يحسب بدقة:
     - **المواقع الشغالة (Online)**.
     - **المواقع الواقعة (Down / Offline)** مع وميض تنبيهي في حال وجود أي موقع واقع.
     - **نسبة كفاءة المنظومة (Uptime %)** مع شريط تقدم ملون.
     - **متوسط زمن الاستجابة (Average Latency)** وتاريخ ووقت آخر فحص.

3. **إجراءات البطاقات التفاعلية (Card Actions)**:
   - تم الاكتفاء بالإجراءات التشغيلية الطبيعية لصفحة المراقبة:
     - 🔄 **إعادة الفحص والتحميل**: لتحديث حالة واتصال الموقع داخل الـ iframe فوراً.
     - ⛶ **ملء الشاشة**: لتكبير شاشة العرض وتصفح الموقع بحجم كامل.
     - ↗ **فتح في نافذة جديدة**: لفتح رابط الموقع مباشرة في تبويب خارجي منفصل.
   - تم إلغاء أزرار التعديل والحذف من البطاقات لتكون الواجهة طبيعية وعملية كصفحة مراقبة حية دون عمليات تعديل غير منطقية.

4. **تحديث دوري وبحث وفلترة**:
   - مؤقت فحص دوري تلقائي قابل للضبط (معطل، كل 30 ثانية، دقيقة، دقيقتين، 5 دقائق) مع عداد تنازلي مرئي.
   - شريط بحث فوري لتصفية المواقع بالاسم أو الرابط.
   - أزرار تصفية سريعة: عرض الكل، المواقع الشغالة فقط، أو المواقع الواقعة فقط.

## 📝 سجل التحديثات الأخيرة (Recent Updates)

- **اعتماد خط Rubik**: تم تطبيق خط **Rubik** (عبر Google Fonts) كخط أساسي وشامل للوحة لكافة النصوص العربية والإنجليزية والأرقام والمؤشرات لإضفاء طابع بصري حديث ومتناسق.
- **إزالة بطاقة إجمالي المواقع**: تم حذف بطاقة "إجمالي المواقع: 4" من شريط الإحصائيات لتبسيط المؤشرات وإعطاء مساحة أكبر لإحصائيات الحالة الحية المباشرة (الشغالين، الواقعين، الكفاءة، سرعة الاستجابة).
- **تبسيط الترويسة العلوية وإزالة Masa Pulse Monitor**: تم استبدال العنوان الإنجليزي المعقد بشعار وعنوان عربي أنيق "مراقبة المواقع الحية" وشارة فحص حي، مع إزالة زر "إضافة موقع" لتقتصر الترويسة بشكل مباشر وبسيط على زر "فحص الكل" ومؤقت الفحص الدوري.
- **إزالة قائمة اختيار التخطيط وزر استعادة الافتراضي**: تم حذف القائمة المنسدلة لاختيار التخطيط وزر الاستعادة من شريط التحكم العلوي، وتثبيت التخطيط تلقائياً على شبكة 2 × 2 لواجهة أكثر بساطة ونظافة.
- **إزالة أزرار الحذف والتعديل من البطاقات**: تم حذف أيقونتي الحذف (Trash) والتعديل (Edit) من ترويسة بطاقات المواقع، لتبقى الإجراءات مقتصرة على الفحص والتكبير والفتح الخارجي.
- **إزالة زر الاستيراد السريع (Bulk Import)**: تم إلغاء الزر والنافذة الخاصة به لتبسيط الواجهة وتركيز العمليات.
- **إزالة كافة المواقع التجريبية الإضافية**: تم مسح المواقع التجريبية/الوهمية الخمسة التي كانت موجودة سابقاً والاكتفاء بالمواقع الـ 4 الرسمية.
- **تحديث التخطيط الافتراضي**: تم ضبط التخطيط الافتراضي للشبكة ليصبح **2 × 2** (4 شاشات متناسقة) كخيار قياسي.
- **نظام ترحيل التخزين المحلي**: تنظيف تلقائي لأي بيانات تجريبية كانت مخزنة في المتصفح سابقاً.

## 💻 طريقة التشغيل (How to Run)

المشروع مبني بتقنيات الويب القياسية (HTML5 / Vanilla CSS3 / Modern JavaScript):

1. فتح ملف `index.html` مباشرة في أي متصفح ويب حديث.
2. أو تشغيل الخادم الخفيف المرفق:
   ```bash
   node server.js
   ```
   ثم فتح الرابط: `http://localhost:8089`.
