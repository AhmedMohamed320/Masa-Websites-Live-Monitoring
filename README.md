## 🌟 أبرز المميزات (Key Features)

1. **عرض حي ومتزامن عبر الـ iFrames**:
   - تقسيم شبكي متناسق ومريح لعرض المواقع المعتمدة بأعلى وضوح وتناسق مرئي.
   - تحميل ذكي وسلس مع مؤشر تحميل دائري لكل إطار.
   - وضع ملء الشاشة لكل موقع (Fullscreen Expand) لتصفحه بحجم كامل دون مغادرة اللوحة.

2. **نظام فحص الحالة والجاهزية (Uptime & Latency Engine)**:
   - فحص استجابة الخوادم لحظياً واحتساب زمن الاستجابة بالمللي ثانية (`Latency ms`).
   - شارة حالة ذكية لكل موقع:
     - 🟢 **متصل (Online)** مع سرعة الاستجابة.
     - 🔴 **غير متصل (Offline)** مع إشعار تنبيهي وزر فتح مباشر.
     - 🟡 **جاري الفحص (Checking)**.
   - شريط إحصائي علوي يحسب بدقة:
     - **المواقع المتصلة (Online)**.
     - **المواقع غير المتصلة (Offline)** مع وميض تنبيهي في حال وجود أي موقع غير متاح.
     - تاريخ ووقت آخر فحص لحظي بجانب مؤقت الفحص التلقائي.

3. **إجراءات البطاقات التفاعلية (Card Actions)**:
   - تم الاكتفاء بالإجراءات التشغيلية الطبيعية لصفحة المراقبة:
     - 🔄 **إعادة الفحص والتحميل**: لتحديث حالة واتصال الموقع داخل الـ iframe فوراً.
     - ⛶ **ملء الشاشة**: لتكبير شاشة العرض وتصفح الموقع بحجم كامل.
     - ↗ **فتح في نافذة جديدة**: لفتح رابط الموقع مباشرة في تبويب خارجي منفصل.
   - تم إلغاء أزرار التعديل والحذف من البطاقات لتكون الواجهة طبيعية وعملية كصفحة مراقبة حية دون عمليات تعديل غير منطقية.

4. **تحديث دوري وبحث وفلترة**:
   - مؤقت فحص دوري تلقائي قابل للضبط (معطل، كل 30 ثانية، دقيقة، دقيقتين، 5 دقائق) مع عداد تنازلي مرئي.
   - شريط بحث فوري لتصفية المواقع بالاسم أو الرابط.
   - أزرار تصفية سريعة: عرض الكل، المواقع المتصلة فقط، أو المواقع غير المتصلة فقط.

#### 2. تشغيل المشروع كخدمة مستمرة في الخلفية بواسطة `PM2`:
```bash
# تشغيل السيرفر وضمان إعادة تشغيله تلقائياً عند أي إعادة تشغيل للسيرفر
pm2 start server.mjs --name "masa-pulse"
pm2 save
pm2 startup
```

#### 3. ضبط خادم Nginx كـ Reverse Proxy (مع الدومين أو السب دومين):
أنشئ ملف إعداد Nginx وليكن `/etc/nginx/sites-available/masa-pulse`:
```nginx
server {
    listen 80;
    server_name monitor.masainternationalgroup.com; # ضع الدومين أو السب دومين المطلوب

    location / {
        proxy_pass http://127.0.0.1:8088;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
}
```
تفعيل الموقع وإعادة تشغيل Nginx:
```bash
ln -s /etc/nginx/sites-available/masa-pulse /etc/nginx/sites-enabled/
nginx -t && systemctl reload nginx
```

certbot --nginx -d monitor.masainternationalgroup.com
